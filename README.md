# GestionDeCamiones
Es un sistema de gestión operativa para empresas de recolección de residuos. Permite administrar toda la operación diaria: los camiones de la flota, las rutas de recolección, los servicios asignados a cada cliente, y las tareas que ejecutan los choferes cada día.

# Stack tecnico / Herramientas utilizadas
Java + Spring Boot, JPA/Hibernate, base de datos relacional. API REST lista para ser consumida por cualquier frontend o app mobile.
